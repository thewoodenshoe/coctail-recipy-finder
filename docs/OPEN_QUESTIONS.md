# Open Questions

These questions should be answered before or during the first application build. Do not over-expand this list without a practical reason.

1. Should the MVP be local-only first, or built immediately with Ubuntu deployment in mind?
2. Should there be any access control for the MVP if deployed on a public IP?
3. Should extracted recipe fields be editable in the first version, or only viewable?
4. What Instagram URL formats should be accepted first: posts, reels, or both?
5. Should one Instagram post be allowed to contain multiple cocktail recipes?
6. Should search prioritize ingredients over caption text?
7. What is the minimum useful import batch size: one post at a time only, or paste several post records at once?
8. Should AI-assisted extraction be used in the first implementation, or should deterministic parsing come first?
